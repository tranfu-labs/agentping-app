如果 macOS 提示“已损坏，无法打开”

这是下载隔离触发的安全拦截。解压后打开终端运行下面命令，再双击 App。

xattr -dr com.apple.quarantine ~/Downloads/AgentPing.app

当前能力

  • 每 60 秒检查一次 OpenAI 与 Anthropic 链路。
  • 用绿色、黄色、红色告诉你是否适合继续。
  • 显示当前出口大致地区，方便判断节点是否切换成功。
  • 可以复制诊断报告，方便发给团队成员一起排查。
  • 点开菜单能看到可能原因和下一步动作。
  • 不读取 API Key，也不读取你的请求内容。

不想开 App，也可以直接跑一次。

适合在 Agent 卡住后快速确认：是网络链路异常，还是工具本身需要处理。

基础检查

./agentping check

显示明细

./agentping check --verbose

它会看哪些链路？

Ageng网络医生不把用户丢进复杂网络日志里，而是把检查结果映射成你正在用的软件状态。

Codex

重点看 OpenAI 链路是否可用，适合判断 Codex 当前能不能继续跑。

Claude Code

重点看 Anthropic 链路是否可用，适合判断 Claude 是否卡在网络返回上。

Cursor

根据当前模型来源判断，OpenAI、Anthropic 和自定义模型都可能影响它。

本地代理

检查终端代理是否生效，避免浏览器能上网但 Agent 请求没走代理。

复制诊断报告，方便发给别人看。

报告会用人话说明：现在什么正常、什么异常、更像哪里出问题、下一步该做什么。

适合什么时候复制？

Agent 长时间没输出、团队成员帮你看节点、或者你想记录一次网络异常时。

报告里不包含什么？

不包含 API Key，不包含你的请求内容，也不记录 Agent 的任务上下文。

Ageng网络医生 诊断报告

Codex / OpenAI：绿色，186ms
Claude / Anthropic：红色，连接失败
本地代理：已检测到，但 Anthropic 不可用

判断：当前出口节点更可能不适合访问 Claude。
建议：先换 Claude 可用节点，再重新运行任务。

看到结果后该怎么做？

不要把它当成复杂网络面板。它只回答一个问题：现在该继续，还是先处理网络。

状态含义建议动作
绿色核心 API 链路可用，延迟正常。可以继续运行 Codex、Claude Code 或 Cursor。
黄色链路能用，但延迟偏高或不稳定。短任务可以继续，长任务先换稳定节点。
红色链路不可用，可能是代理、节点、出口或服务问题。先暂停 Agent，按建议换节点、查代理或等待服务恢复。
